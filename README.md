## 1Gbps 到底能跑多少

1Gbps 标的是端口峰值，你稳定拿到的下载速度通常明显低于这个数。

有测评方在洛杉矶 Global 系列的测试中记录到国内方向普遍跑到 300Mbps 以上，海外方向更接近端口峰值，测试用的是 Speedtest，具体节点和时段未公开。另一个测评方测六六云洛杉矶 1000Mbps 机型时，本地下载跑到 10.8MB/s，约合百兆水平，测评者自己给出的解释是从国内跨太平洋受国际出口限制，跑不满 1000Mbps 属正常现象，不能据此判定虚标。

两组数据差了一个数量级，测试条件不同，不能合并成一个结论。能确定的是，端口速率决定的是机房出口和多线程场景的上限，单线程跨洋下载通常受制于国际出口和你本地宽带，标称数字和体感速度之间隔着这一段。

## 线路决定体验下限，回程比去程更要紧

对国内访问来说，线路优先级是 CN2 GIA > CN2 GT > 普通 163。CN2 GIA 走 59.43 节点，三网直连、延迟低，这是第三方测评的通行口径，不是运营商的 SLA 承诺。

回程方向比去程更影响真实体验。六六云那篇测评里有一句说得很到位：实际使用中大部分流量走的是回程方向，网页加载、文件下载都靠回程，所以回程直连对真实体验的影响比去程大得多。它测的那台机器联通去程绕德国节点、Ping 256ms，但三网回程全部直连回国，本地下载仍有 10.8MB/s。

RackNerd 的公开资料里提到用 Noction IRP 做路由优化，没有宣称走 CN2 GIA 或 9929 这类中国优化线路。面向欧美用户的独立站、海外 API 调用、流媒体落地这些场景，国际线路够用，不必为国内方向优化付溢价。国内访问为主的落地和中转，得另找明确标注中国优化的产品线。

## 四条只在条款里写着的限制

**流量跑超之后怎么办。** 这条直接决定大流量业务会不会突然断掉。IDC.Net 的规则是超出后限速 10Mbps、不额外收费；ZgoVPS 洛杉矶 Global 系列标了 Fair Use，超出后一般限速或暂停，具体看执行。RackNerd 的促销页会给每档标注月流量配额（512MB 档 500GB、2GB 标准档 2TB），超出后的处理方式写在当次促销页里，不同批次不一定相同，下单前自己看一眼。

**退款。** IDC.Net 提供 3 天无理由退款，每位会员每个机房限 1 次，支付手续费自付；六六云是 48 小时内可退；ZgoVPS 的 Global 系列官网明确写不支持退款。RackNerd 的条款默认不提供退款，促销页会另行注明条件。把它当成买定离手来评估预算，比事后找客服强。

**IP 的隐形成本。** IDC.Net 开通 24 小时内故障 IP 免费换一次，超出 24 小时或主动换 IP 收 50 元一次，加 IP 15 元一个，IP 因垃圾邮件进黑名单要 200 元清洗费。RackNerd 每个套餐含 1 个独立 IPv4，洛杉矶和法国机房可申请最多 100 个免费 IPv6，做多 IP 站群的成本结构完全不同。

**防御。** 小鸡云圣何塞 4837 系列标了 50Gbps 原生防护；IDC.Net 明确写不含防御，遭攻击临时暂停直至攻击结束，频繁被攻击可能移除且不退款。RackNerd 的 VPS 促销页没有把 DDoS 防护列进标配。做站群、跨境店铺这类容易被盯上的业务，这条比 CPU 核数重要得多。

RackNerd 的服务条款还把 VPS 定为无管理（unmanaged），支持范围限于硬件、电力、网络连通性和服务可用性，软件、操作系统、应用、防火墙配置、脚本调试都在范围之外，需要有人管系统要另外付费。

**个人博客、静态站、探针、学习练手** → 1GB 档，年付折算约 $1.83/月。512MB 档年付 $26.99，比 1GB 贵，除非你正好需要那一批的机房位置，否则没理由选它。

**国内访问为主的落地或中转** → RackNerd 不对路，去看明确标 CN2 GIA、9929 的产品线。也可以折中：一台中国优化线路的小机器做前端，RackNerd 放后端落地，成本比全程走优化线路低。

**跑 AI 应用** → 官方一键应用里，OpenClaw 要求至少 8GB 内存，Ollama、AnythingLLM、LibreChat、Hermes Agent 要求 4GB 起，n8n 和 Coolify 从 2GB 起。跑本地模型直接上 4GB 档，2GB 只能应付工作流类应用。

**多站点站群** → RackNerd 每台含 1 个 IPv4，IPv6 可工单申请。真要 20 个独立 IPv4 的站群，IDC.Net 那种自带 20 IP 的套餐（500 元/月）才是对口产品。
